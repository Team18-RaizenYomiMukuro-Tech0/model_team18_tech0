## 始め方
1. クローンしたら、秘密情報の混入を止めるフックを有効にする（各自1回）。
   ```bash
   git config core.hooksPath .githooks
   ```
2. `CLAUDE.md` と `00_ルール/V字フロー規定.md` を読む。
3. PR のレビューとマージの決まりは `00_ルール/PRレビュー規定.md`。
4. 週1要約の定期実行・失敗の自動吸い上げを入れる（任意）。OS に合わせて、Mac は `01_ナレッジ/定期実行の導入手順.md`、Windows は `01_ナレッジ/定期実行の導入手順_Windows.md`。
