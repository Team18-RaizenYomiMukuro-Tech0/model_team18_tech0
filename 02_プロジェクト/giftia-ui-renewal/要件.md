# 要件 — Giftia UI/UX リニューアル

優先: R-01 を先に仕上げ、R-02 は R-01 に必要な部分（条件での絞り込み・候補選び・詳細）だけ先に作る（ADR-002）。

## 機能要件

| 要件ID | 要求ID | 満たすこと | 測定できる基準 |
| --- | --- | --- | --- |
| F-01 | R-01 | 利用者の入力（予算の総額・シーン）を受け、商品 DB から複数の候補を取り出し、チームが設計したロジックで順位付けして返す（ケース Exhibit 5 の必須の流れ） | 送別・予算 4,500円の入力で、送別タグを持ち予算内の商品だけが、順位付きで返る。順位付けのルールは F-01a と仕様 SP-02 |
| F-01a | R-01 | 順位付けのロジック: 評価の高い順。ただし件数が少ない商品は割り引く（質問22「B」） | 評価4.9・3件より評価4.6・120件が上に来る。割り引きの式と係数は仕様で定義 |
| F-02 | R-01 | 各候補に、仲間の同意の材料になる理由を付ける。理由は既存の列の組み合わせだけで作る（ADR-003、質問20「C」、#23・#29） | 事実をテンプレートでつなげた自然な文で表示する（AI は使わない。30字の制限なし、分かりやすさ重視）。材料は「職場の送別で贈られた回数（注文の推定シーン＝送別かつ会社宛ての件数）」「評価と件数」「配送日数・ラッピング可」。値が無い材料は使わない。値を作らない |
| F-03 | R-01 | 候補を選んで、まとめておける | 1つ以上、上限なしで選べる（#23） |
| F-04 | R-01 | 選んだ候補をまとめた共有リンクを作る | サイトを閉じずに、1回の操作の流れの中でリンクが作られる（AC-01） |
| F-05 | R-01 | 共有リンクをログインなしで開ける | ログインなしでスマホ幅の画面から開くと、選んだ候補と理由が表示される（AC-02） |

R-02 の機能要件は、要求.md の旧 ID 対応表（HDR・SRC・FAV・RAT 等）を元に、R-01 に必要な部分から追記する。

## 非機能要件

| 要件ID | 要求ID | 性能・使いやすさ・環境・安全 | 測定できる基準 |
| --- | --- | --- | --- |
| N-01 | R-01 | 共有リンクはスマホで読める | スマホ幅 375px（OPEN-01 で決定）で、横スクロール・文字欠けが無い |
| N-02 | R-01 | 共有リンクは他人に推測されにくい | リンクの識別子は連番ではなく、推測しにくい値にする（具体は仕様） |
| N-03 | R-01 | 待たされずに進める（速さ） | 手元の PC から班の DB につないで各10回測り、遅い方から2番目の値で、候補表示2秒以内・共有リンク作成1秒以内・共有ページ表示1秒以内。性能テストで測り数値を証拠に残す。超えたら注文テーブルへの索引追加を設計し、既存テーブルの変更なので足す前にレージに確認する（キックオフ記録 #34 7-1・7-2） |
| N-04 | R-01 | DB を守る | 問い合わせは必ずパラメータ化クエリ（入力値を SQL 文に直接つなげない）。DB との通信は SSL（#28 の証明書）。接続アカウントは既存テーブルの読み取りだけ、書き込みは共有リンク用テーブルだけ（#34 7-3） |
| N-05 | R-01 | 表示した文字でスクリプトが動かない | 画面に出す文字は必ずエスケープする。React の通常の表示だけを使い、HTML をそのまま差し込む書き方を禁止する（#34 7-4） |
| N-06 | R-01 | 使いすぎを防ぐ | 共有リンク1本に入れられる商品は10件まで。11件以上で作ろうとしたら入力エラー。画面での選択は上限なしのまま。作成回数の制限は外部公開の承認後に決める（#34 7-5） |
| N-07 | R-01 | 共有ページを広く公開しない | 共有ページは検索エンジンに載せない（noindex）。API は自サイトの画面からだけ呼べるよう CORS を絞る（外部公開の承認後に設定）（#34 7-6） |

## 通常ルート

架空データを使う。秘密情報をコミットしない。mainへ直接pushしない。入力検証とエラー処理を保つ。

技術条件（ケース Exhibit 5）: フロントエンド Next.js、バックエンド FastAPI、DB はケース提供の MySQL（班の DB `giftia_t501`）。

## 任意の発展

認証、認可、実データ、外部公開、追加サービスは、目的、データ、リスク、戻し方を運営へ相談し、人の承認後に着手する。
