## 💬 これは何？（ひとことで）
API 全体が使う土台。変えうる値を 1 か所に集めた設定、DB への問い合わせを一手に引き受ける `Db`（10 秒の打ち切り・SSL・パラメータ化クエリ）、差し替えられる `Clock`、IP とブラウザ情報を残さないログ。

## ✅ 完成すると何ができる？
- 変えうる値が 1 か所にまとまっている（→ 完了条件 #1）
- DB への問い合わせは 10 秒で打ち切られる（→ 完了条件 #2）
- 入力値を SQL 文に直接つなげず、パラメータ化クエリだけを使う。接続先は `giftia_t501` に固定（→ 完了条件 #3）
- DB 通信が SSL で、certifi の公開の証明書の束を使いホスト名を確かめる。証明書の環境変数は使わない（→ 完了条件 #4）
- `backend/database.py` の2つの読み取りを直す: DB 名は定数 `giftia_t501`（`GIFTIA_DB_NAME` を読まない）、SSL は certifi の束（`GIFTIA_DB_SSL_CA` を読まない）。`backend/requirements.txt` に `certifi` を足し、`backend/.env.example` から2つの名前を消す（→ 完了条件 #3・#4）
- ログに時刻・API・結果だけが出て、IP とブラウザ情報は出ない（→ 完了条件 #5）
- テストでだけ時刻と遅れを差し替えられ、本番に入口が無い（→ 完了条件 #6）
