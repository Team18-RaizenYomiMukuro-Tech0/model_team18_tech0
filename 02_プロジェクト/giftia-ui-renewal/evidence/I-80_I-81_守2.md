## 気づいたこと（判定には影響しない）

- ④`/s/bad` は HTTP 200 で返る。共有ページの枠は id の形に関係なく同じ枠を返す作り（テスト設計 NF-63 の「枠の応答は id によらない」と同じ）。ヘッダーの期待は満たす。
- ③④の応答には `Cache-Control: private, no-cache, no-store` があり、①②（`s-maxage=31536000`）と違う。今回の変更の前からの挙動で、守りのヘッダーとは関係しない。
- `x-nextjs-prerender: 1` が ①②⑤で 2 行出る。Next.js 自身の出力で、守りのヘッダーではない。5ヘッダーと `X-Robots-Tag` は重複していない。
- `curl -sI http://127.0.0.1:8791/api/products`（HEAD）は 405 を返す。API は GET だけを許す作りのため。GET で確かめた（応答は 200）。
- 手元の API は `GET /api/products` の応答に `X-Robots-Tag` が付く一方、HSTS 等は付かない。N-20 の対象外（API には足さない）と一致。
- 3100 番を、私以外の別の node（PID 53164）が使っていた。古い版の画面で、5ヘッダーが無く `X-Powered-By: Next.js` が出ていた。止めずに 3187 番で起動し直して確かめた。最初の応答（3100 番）は証拠に使っていない。
