## 手順 3d（`share_likes` の後片付け。手順 3 の前に流した）

`db_admin.py` に 3d は無い（`DB管理手順.md` の注）。同じ接続（`db_admin.open_connection()`、autocommit なし）で、手順書の 3d の SQL（WHERE は手順書のとおり）をそのまま流した。使い捨ての短い script で、コミットしていない。

| 確認 | 件数 |
| --- | --- |
| 流す前の `share_likes` 全体 | 16 |
| `to_delete`（手順書の 3 条件のどれか） | 16 |
| うち `is_test=0` の共有リンクの分 | 0（期限内の本物のリンクの行は混じっていない） |
| `DELETE` の `ROW_COUNT()` | 16（`to_delete` と一致。COMMIT） |
| 流した後の `share_likes` 全体 | 0 |
| 流した後に条件へ当てはまる行 | 0 |
| `share_links`（流した前後。この手順では変わらない） | `is_test=1` が 25、`is_test=0` が 4 のまま |

その後に上の手順 3 を流し、`is_test=1` の 25 行を消した（`is_test=0` の 4 行は前後で同じ）。
