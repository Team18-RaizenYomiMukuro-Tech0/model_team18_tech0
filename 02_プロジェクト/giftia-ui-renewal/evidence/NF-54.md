# NF-54 本番の API の速さ（読むだけ） — 新基準で測り直し（2026-11-17）

- 実行: Kurosu。手元の Mac から本番の API（`<APIの URL>`）へ HTTP の GET を 10 回ずつ。温めなし・1 回目も数える・回を除かない。起点: main `25e6782`（#403 新基準・#404 起動を軽くする・`/api/products` に Server-Timing）。詳細だけ main `2002d58`（#405 詳細にも Server-Timing）で測り直した。接続先のホスト名・接続情報は書かない。
- 新基準（テスト設計「起動したての回の扱い」。PM 11/17「C+D」）: 応答の `Server-Timing` の `nth=1` を「起動したて」とする。**①起動したて以外の回を短い順に並べ、遅い方から 2 番目が基準以内、②起動したての回はすべて 6 秒以内**。2 つとも満たして ○。起動したて以外が 2 回未満なら測り直す。`Server-Timing` の無い回は「起動したてでない」と数える（推測で免除しない）。
- 使ったもの: 各回の秒と `nth`・`up` を記録する手元の GET だけのスクリプト（`backend/perf/measure.py` は `nth` を記録しないため。リポジトリには入れていない）。Python 3.11・`SSL_CERT_FILE=/etc/ssl/cert.pem`。
