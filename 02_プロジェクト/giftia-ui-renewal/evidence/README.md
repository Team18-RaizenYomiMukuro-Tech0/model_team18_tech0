# evidence — 証拠の置き場

テストの出力、スクリーンショット、各段の自己点検（○△×と根拠）、受入テストの実施記録を置く。
「できたと思う」は証拠ではない。ファイルのパスを示せるものだけが証拠。

## 置き場

- テストごとに `evidence/<テストID>.md`（例: `evidence/U-01.md`）。画面のテストは同名の画像（`evidence/<テストID>.png`）を並べる。
- DB の実行記録は `evidence/db/<日付>_<番号>.md`（接続情報は書かない）。

## 書き方

- ○ または × を 1 つ書く（△ は使わない）。
- 根拠: 期待結果とどう照らしたか（コマンドと出力の最後の行、見た値）。
- 証拠パス: 出力ファイル・画像のパス。パスを示せないものは証拠にしない。

## 合格の決め方（NF-21）

U・I・S・A（と NF-01〜03）がすべて ○ なら合格。1 つでも × なら不合格。`evidence/` の全ファイルの一覧と ○× の表を残す。
