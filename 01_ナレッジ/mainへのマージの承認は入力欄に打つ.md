# main へのマージの承認は、入力欄に「承認します」と打つ（2026-11-25）

origin: internal ／ 根拠: PR #719 で起きたこと（りじちょーの依頼文で受けた）。関連: `エージェント運用の決まり.md` §3、`mistakes/question-in-text-not-asked.md`

## 1. 起きたこと（事実）

- PR #719（通しの確認の期待結果）を main にマージするとき、質問の画面で利用者が選んだ答えだけでは、自動の判定に止められた。

## 2. 決まり

- main へのマージの承認は、**利用者が入力欄に「承認します」と打つ**。質問の画面の答えだけでは足りない。
- 質問の画面で答えをもらった後は、入力欄で「承認します」をお願いする。
- 承認があるまで、マージはしない（`--admin` のマージは PM の一言があるときだけ。`エージェント運用の決まり.md` §3）。

## 3. 注意

- 自動の判定が何を見て止めたかは、この記事では確認していない。入力欄の文を求める理由は、上の 1 件の経験による。
