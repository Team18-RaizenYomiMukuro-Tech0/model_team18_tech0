# 同じファイルを触る PR を並べる・他の PR の上に積んで衝突する

- 発生回数: 2（2026-11-10。PM 依頼「ミスの記録に残しておいて」で手書き。自動収集ではない）
- 最終発生日: 2026-11-10
- 収集源: PM 依頼（god の報告）
- デプロイ系: いいえ

## 症状

1. **#188**: #187 のブランチの上に作った。#187 が Squash and merge（733963e）されたため、#188 が `scripts/build-review-rule.py`・`scripts/test_build_review_rule.py` で衝突した。Mi-rin が main を取り込んで解消した（force push なし）。
2. **#189 と #190**（どちらも Mi-rin。god が続けて依頼）: `scripts/test_build_progress.py` の末尾に、別々にテストを足した。#189 が先にマージされ、#190 が衝突した。re-ji-tech0 が 5a8277c で解消し、60 tests OK。

## 原因

- 同じファイルを触る PR を、前の PR のマージを待たずに並べて依頼した。
- 他の PR の上に PR を積んだ。このリポジトリは Squash and merge なので、先の PR は別のコミットになり、積んだ側の PR には先の PR の元のコミットが残って衝突する。

## 直し方 / 再発防止

- 同じファイルを触る依頼は、前の PR のマージ後に出す。並べて出すなら、各 PR の本文の「先に入れる PR」に番号を書く。
- 他の PR の上に積まない（`origin/main` から新しいブランチを切る）。積んだ場合は、先の PR のマージ後に main を取り込んで解消する。rebase・force push はしない。
- テストファイルの末尾は衝突しやすい。足す場所が同じになりそうな依頼は特に、順番を決めてから出す。
