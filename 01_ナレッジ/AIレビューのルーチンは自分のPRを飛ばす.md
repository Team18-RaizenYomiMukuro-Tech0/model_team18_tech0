# AI レビューのルーチンは自分の PR を飛ばす（2026-11-25）

origin: internal ／ 根拠: `00_ルール/PRレビュー規定.md` §2（手順 2）、`scripts/scheduled/review-routine-prompt.md` 27〜33 行（候補の条件）、`レビュールーチンの設定手順.md`。PM の決定 11/25（りじちょーの依頼文で受けた）

## 1. 仕組み（事実）

- AI レビューは、各メンバーが自分の claude.ai アカウントで作るルーチンが動かす。
- ルーチンは、**自分が出した PR を飛ばす**（規定 §2 の手順 2「本人は承認できない」。指示文の候補の条件「作者が自分ではない」）。
- 承認は、ルーチンを動かしている人の名前で記録される（規定 §4）。

## 2. 起きうること（規定と指示文から導いた帰結）

- 3 人のうち、ルーチンを設定した人が少ないと、**設定していない人名義の PR を、AI は誰もレビューしない。** 設定した人のルーチンは自分の PR だけを飛ばすので、他の人の PR は見る。
- 設定した人が 1 人だけなら、その人の PR を見る AI は 1 人もいない。
- AI が見ない PR は、人のレビュー（`needs-human` の早い者勝ち。規定 §4）に頼ることになる。

## 3. PM の決定

- 今のまま（仕組みは変えない）。2026-11-25。

## 4. 守ること

- 自分の PR に AI の判定が付かないときは、まず設定した人の少なさを疑い、人のレビューを頼む。
- 実際に誰が設定済みかは、この記事では確認していない（設定は各自の claude.ai の画面で、リポジトリから見えない）。
