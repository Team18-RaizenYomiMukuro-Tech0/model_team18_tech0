🧭全体像

何を作るか

予算（任意）とシーン（お礼・誕生日・送別）を入れて候補を出し、選んだ候補を共有リンクにして仲間に送れるようにする。

中心の問い: ギフトを探す人が、条件で絞って比較し、1つに決めるまでを、迷わずに進められるか？

R-02: 共通ヘッダー・トップ・検索条件・カード型の結果・詳細・お気に入り・カートがそろった画面で、探して比べられるようにする。R-01 の体験は、この画面の土台に載せる。

対象: R-01 共同購入者（職場の送別などで、仲間とお金を出し合って贈る人）／R-02 Giftia のサイト訪問者（R-01 を含む）。

ユーザーの流れ

右の印は、作る段。

  1. 予算・シーンを入れる　実装①
  2. 候補を出す　実装①
  3. 選ぶ　実装②
  4. 共有リンクを作る　実装②
  5. 仲間がスマホで開く　実装②

R-02（サイトを探す人）:

  1. トップでシーン・価格帯・カテゴリーを選ぶ　実装②
  2. 検索結果で条件を変える（その場で結果が替わる）　実装②
  3. カードを12件ずつ見て、ページを送る　実装②
  4. 詳細の欄で確かめる　実装②
  5. お気に入り・カートに入れる　実装②
