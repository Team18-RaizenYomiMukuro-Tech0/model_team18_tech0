# モック置き場（docs/mock/）

完成イメージを見せるための置き場です。**モックは2段階**で作ります。仕様がまだ無い間は画面の中身を作りません（仕様に書かれていないことは補わない）。

## 第1段階：要件段階の紙芝居（3〜5枚）

- 目的：要件（F/N）が固まった時点で、「こういう流れで使う」をチーム全員で確認する。
- 形：静止画・簡単な HTML のどちらでもよい。**3〜5枚**で主要な流れを順にめくる。
- 各枚に対応する要件 ID（F/N）を書く。
- 置き場：`docs/mock/kamishibai/`（作成時に追加）

## 第2段階：仕様段階のクリックで動くモック

- 目的：仕様（SP）が固まった時点で、画面遷移と操作を実際にクリックして確かめる。
- 形：素の HTML/CSS/JS（外部ライブラリなし）。
- **各画面に SP 番号を表示する**（どの仕様に対応する画面か分かるように）。
- 置き場：`docs/mock/clickable/`（作成時に追加）

## 案A/案Bの見比べ

決めることがある論点は、案A・案Bのモックを並べて、開発ハブの「🙋 決めること・決めたこと」から見比べられるようにする。決定（誰が・なぜ・本人回答）は同じ欄に残す。

## 守ること

- 実データ・秘匿値は載せない。架空データだけを使う。
- 主要フロー図・画面遷移図・ER図もここ（または `docs/` 配下）に置く。
